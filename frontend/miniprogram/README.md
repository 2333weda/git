# 学生端小程序（frontend/miniprogram）

微信小程序（原生），唯一学生入口。对应需求说明书 4.1 节 S-01 ~ S-06。

## 规划结构

```
miniprogram/
├─ pages/
│  ├─ availability/   S-01 空档查询
│  ├─ booking/        S-02 预约下单
│  ├─ checkin/        S-03 扫码签到
│  ├─ bookings/       S-04 我的预约
│  ├─ appeal/         S-05 取消与申诉
│  └─ credit/         S-06 信用分
├─ utils/             请求封装、时间与时段工具
├─ components/        时段条、场地卡片等
├─ app.json / app.js
└─ project.config.json
```

## 主流程

```
S-01 选时段 → S-02 下单 → S-04 看状态 → 到店 S-03 签到
                    S-04 → S-05 取消/申诉 → S-06 信用分
```

## 约定

- 时段选择器只提供 `:00` / `:30`，非整 30 分钟的提交由服务端拒绝（`SLOT_ALIGN_INVALID`）
- 预约表单失败时保留已填内容，并按错误码给出文案与最近可约时段
- 签到码短时效、仅本人可见，禁止转借；截图转发按无效处理
- 不引入 npm 构建链，保持原生工程，便于微信开发者工具直接导入
