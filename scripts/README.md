# 本地开发与压测脚本（scripts）

放一次性可复现的脚本：初始化、数据重置、压测。脚本本身入库，产出的数据与日志不入库。

## 规划脚本

| 脚本 | 用途 |
| --- | --- |
| `reset-db.*` | 重建库并导入 `db/schema.sql` + `db/seed.sql` |
| `seed-cases.*` | 按需求说明书第 5.2 节固定数据造场：场地 A/B、维护窗口 |
| `pressure-booking.*` | 50 并发抢同一时隙（TC-15），输出成功/失败计数 |
| `check-*.ps1` | 提交前自检：残留密钥、`node_modules`、大文件 |

## 约定

- 脚本首行写用途、参数与示例，参数缺省时不能误删生产库
- 压测脚本默认只打本地或测试环境，地址必须显式传入
- 时间推进（TC-12 / TC-21 / TC-24 需要跨 14 天或 15 分钟）通过测试时钟开关实现，不靠真实等待，也不改业务代码
