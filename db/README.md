# 数据库（db）

MySQL 8，建表脚本与种子数据。结构变更走 `chore/` 或对应功能分支，并在 MR 里注明"是否动表结构"。

## 规划结构

```
db/
├─ schema.sql        建表脚本（时隙、预约、场地、用户、日志等）
├─ seed.sql          验收固定数据：场地 A / 场地 B / 维护窗口
└─ migration/        增量变更，按日期编号 V20261201__xxx.sql
```

## 关键设计

- **时隙占位防并发**：`(resource_id, start_at, status)` 上建唯一约束，配合事务内写入，保证 50 并发只有 1 条成功（C-07）。
- **状态机**：`PENDING → CHECKED_IN → COMPLETED`，异常分支 `NO_SHOW` / `CANCELLED`；状态流转历史只追加不改写。
- **操作日志**：只追加、无删除接口，保留 180 天；记录操作人、时间、对象、改前改后、来源 IP。
- 时间统一存 UTC，展示按 Asia/Shanghai；业务判定用左闭右开区间 `[start_at, end_at)`。

## 验收固定数据

| 数据 | 用途 |
